## Notes

- The CI/CD badge uses `.github/workflows/ci-cd.yml`.
- The release badges require GitHub releases. Release Downloads counts downloads of release assets, **not** source archives or container pulls.
- The license badge requires a recognized license file (for example, `LICENSE` containing the MIT license).
- The Docker label is **static**: it does not verify that an image exists.
- The Docker Image Size badge works only if the `ghcr.io/tupinumboor/chatgpt-max-bot:latest` image is published and publicly accessible. The tag and path must match the actual package.
- GitHub's language statistics can take time to update and may classify shell scripts differently depending on repository contents.
- A missing value or `not found` often means the relevant resource is not published yet, or the badge service has not refreshed its cache.
